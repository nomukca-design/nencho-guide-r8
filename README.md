# 年末調整かんたんガイド（令和8年分）

従業員が、年末調整の申告書のどの欄に何を書くかを確認するためのウェブアプリです。
入力内容はブラウザの中だけで計算し、どこにも送信しません（サーバー不要の静的サイト）。

## 対応している申告書
- 給与所得者の扶養控除等（異動）申告書
- 基礎控除申告書／配偶者控除等申告書／特定親族特別控除申告書／所得金額調整控除申告書（兼用様式）
- 保険料控除申告書（生命保険料・地震保険料・社会保険料・小規模企業共済等掛金。23歳未満の扶養親族がいる場合の生命保険料控除の特例に対応）

- 住宅借入金等特別控除申告書（2年目以降。平成29年〜令和7年の入居。連帯債務・取得対価・居住用割合・所得要件に対応。種類が合わない場合は申告書の印字どおりに限度額を入力できる）

未対応：国外居住の親族、住宅ローンの借換え・再取得の特例・特例居住用家屋（40㎡以上50㎡未満）、12月より前の年末調整（改正前の金額）。

## ファイル
| ファイル | 役割 |
|---|---|
| `index.html` / `css/style.css` | 画面 |
| `js/app.js` | 入力と表示 |
| `js/calc.js` | 判定・計算（画面に依存しない） |
| `data/r8.js` | 令和8年分の金額・境目（出典つき） |
| `data/glossary.js` | ことばの解説（画面の文章から自動でリンクされる） |
| `test/calc.test.js` | 国税庁の表の境目で検算するテスト |
| `serve.js` | 手元で確認する簡易サーバー |

## 手元で確認
```bash
node serve.js
```
http://localhost:8765 を開きます。テストは `node test/calc.test.js`。

## 公開（GitHub Pages の例）
1. GitHub に新しいリポジトリを作り、このフォルダの中身をアップロード
2. Settings → Pages → Branch を `main` / `/(root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

Cloudflare Pages や Netlify でも、このフォルダをそのままアップロードすれば動きます（ビルド不要）。
